# 灵动分段（BubbleReply）

把一条较长回复拆成多条自然的聊天气泡，并在发送过程中保护正文、图片、表情和 Reply 顺序。

## 功能

- 按真实换行和自定义标记分段。
- 可清理每段首尾空格，清理后为空的分段不会发送。
- 可调用独立模型寻找更自然的分段位置。
- 智能分段只能调整换行，不能改写正文。
- 支持图片、平台表情和 At 的发送位置设置。
- 支持始终引用原消息，或只在有消息插队时智能引用。
- 文件、语音、视频等特殊内容自动交给 AstrBot 发送。
- 发送异常时优先避免重复消息。
- 流式回复不会分段，并会自动跳过颜文字协议，避免内部标签进入流内容。
- 默认日志不记录完整正文和账号。

## 会话黑名单

每行填写一个目标：

```text
G:10001
F:10002
```

- `G:` 表示群聊群号。
- `F:` 表示私聊用户 QQ 号。

## 智能引用

选择“智能引用”后，如果生成回复期间同一会话出现了新的入站消息，灵动分段会自动引用原消息，避免回复位置产生歧义。钉钉平台不支持此功能。

为了观察不调用模型的插队消息，插件只在启用智能引用时注册轻量消息观察器。群聊普通消息不会因此触发模型回复。

## 智能分段

智能分段适合低温度、指令遵循较好的模型。插件会严格检查模型输出：如果模型修改文字、标点或空格，本次建议会被拒绝，并自动回退普通分段。

配置中的删除和清理规则使用正则表达式，实际由 Python `re` 执行，并遵循 Python 正则语法。

## 安装

将 `bubble_reply` 目录放入 AstrBot 的 `data/plugins/`，然后在 Dashboard 中启用或重载“灵动分段”。支持 AstrBot `>=4.26,<5`。

建议关闭 AstrBot 核心自带的分段回复，避免重复分段。
